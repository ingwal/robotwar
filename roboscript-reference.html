Execution model

RoboScript runs once per frame — about 60 times per second. Each frame the interpreter loads fresh sensor values, executes your code from the top, and applies any outputs you wrote before returning control to the game.

  • Regular variables are reset to 0 at the start of every frame.
  • mem[0]…mem[63] and named arr arrays persist across frames — use them for state.
  • You have a budget of 4 000 instructions per frame. If your code takes longer, execution is cut off and the last written outputs are used.
  • All values are floating-point numbers. There are no strings, booleans, or arrays. The number 0.0 is false; anything else is true.
Tip: Think of your script like a control loop body, not a complete program. It runs repeatedly, so avoid trying to wait or loop for multiple frames — instead store state in mem[] and let the frame cycle do the looping.

Variables

Declare a variable by assigning it. All variables are floats.

speed = 1.0
angle = me.turret + 0.1
count = count + 1   -- note: count resets to 0 each frame! use mem[] for counters

Variable names are case-sensitive, start with a letter or _, and may contain letters, digits, and underscores.

Remember: plain variables reset to 0 each frame. Only mem[] and named arr arrays remember their values from one frame to the next.

Control flow

if / elseif / else / end

if hp < 20 then
  -- flee
elseif hp < 60 then
  -- be cautious
else
  -- attack
end

while / do / end

while angle < 6.28 do
  angle = angle + 0.1
  d = scan(angle, 0.1)
  if d > 0 then break end
end
Watch the budget! A tight while loop can exhaust the 4 000-instruction budget. Prefer using mem[] to continue work across frames.

loop / end — infinite loop with break

loop
  angle = angle + 0.1
  d = scan(angle, 0.12)
  if d != 0 then break end
  if angle > 6.28 then break end
end

break and continue

break exits the nearest enclosing loop. continue jumps to the top of the nearest loop.

Tip: Angles use the convention 0 = +Z axis (north), increasing clockwise. To aim at a world position (px, pz) from your position: out.aim = atan2(px - me.x, pz - me.z)

Howitzer

The howitzer lobs a high-arc shell that explodes on impact and damages everything within its blast radius — including walls and friendly robots. It has a 5-second cooldown and a maximum range of world.howitzer.maxRange units (typically 40). The target must also be at least 1 unit away.

Fire it by setting both out.howitzerX and out.howitzerZ to the target world position. The shot is silently discarded if the howitzer is still cooling down or the target is out of range, so always guard with world.howitzer.ready and a range check. 

-- Fire howitzer at last known enemy position (mem[1], mem[2])
-- only when ready, in range, and the fix is fresh.
if world.howitzer.ready and mem[12] == 1 then
  hdx = mem[1] - me.x
  hdz = mem[2] - me.z
  hd  = sqrt(hdx * hdx + hdz * hdz)
  if hd >= 2 and hd <= world.howitzer.maxRange then
    out.howitzerX = mem[1]
    out.howitzerZ = mem[2]
  end
end
Tip: The howitzer is most effective at targets you can't easily reach with radar shots — corners, robots behind walls, or enemies spotted via radio.

Radio (teams only)

In team battles with radio enabled, robots on the same team share a radio channel. RoboScript exposes three message types:

Enemy sightings

  • Send: set out.radioX and out.radioZ to broadcast an enemy position. Optionally also set out.radioVX / out.radioVZ to include your velocity estimate — this lets teammates lead their howitzer shots.
  • Receive: radio.tipX / radio.tipZ — the X/Z of the latest enemy-sighting sent by a teammate this frame. Both are 0 if none arrived. radio.tipVX / radio.tipVZ — the velocity the sender included (0 if not provided).

Position broadcasts (dispersion)

  • Send: set out.sendPos to a non-zero value to broadcast your current position.
  • Receive: radio.posX/Z, radio.pos2X/Z, radio.pos3X/Z — up to three recent teammate positions from a 3-second engine-maintained window (most recent first). Use these to spread out and avoid clustering. No manual caching needed — the engine accumulates them across frames.

Death events

  • Receive only — the game engine sends a death event to every robot (not just teammates) when any robot dies.
  • radio.deathTeamId — team ID of the robot that died (0 if no death this frame).
  • radio.deathX / radio.deathZ — where it died.
  • Compare with me.teamId to distinguish friendly from enemy deaths.

All radio values reset to 0 every frame. Copy anything you need to keep into mem[]. 

-- ---- Enemy tip ----
if d > 0 then
  out.radioX  = me.x + sin(mem[0]) * d   -- broadcast enemy position + velocity
  out.radioZ  = me.z + cos(mem[0]) * d
  out.radioVX = mem[5]   -- smoothed enemy velocity X (stored in mem[5])
  out.radioVZ = mem[6]
end
if not isnan(radio.tipX) then
  mem[20] = radio.tipX   -- cache the tip
  mem[21] = radio.tipZ
  mem[27] = radio.tipVX  -- and its velocity (0 if sender didn't include it)
  mem[28] = radio.tipVZ
end

-- ---- Position broadcast (every 2 s) ----
if world.time - mem[22] > 2.0 then
  out.sendPos = 1
  mem[22] = world.time
end

-- ---- Teammate dispersion ----
-- Engine provides up to 3 recent teammate positions; no manual caching needed.
-- Flee from the average of whichever are within 12 units.
nearX = 0; nearZ = 0; nearCnt = 0
if not isnan(radio.posX) then
  tdx = radio.posX - me.x; tdz = radio.posZ - me.z
  if tdx * tdx + tdz * tdz < 144.0 then
    nearX = nearX + radio.posX; nearZ = nearZ + radio.posZ; nearCnt = nearCnt + 1
  end
end
if not isnan(radio.pos2X) then
  tdx = radio.pos2X - me.x; tdz = radio.pos2Z - me.z
  if tdx * tdx + tdz * tdz < 144.0 then
    nearX = nearX + radio.pos2X; nearZ = nearZ + radio.pos2Z; nearCnt = nearCnt + 1
  end
end
if not isnan(radio.pos3X) then
  tdx = radio.pos3X - me.x; tdz = radio.pos3Z - me.z
  if tdx * tdx + tdz * tdz < 144.0 then
    nearX = nearX + radio.pos3X; nearZ = nearZ + radio.pos3Z; nearCnt = nearCnt + 1
  end
end
if nearCnt > 0 then
  fleeAng = atan2(me.x - nearX / nearCnt, me.z - nearZ / nearCnt)
  out.moveX = me.x + sin(fleeAng) * 24.0
  out.moveZ = me.z + cos(fleeAng) * 24.0
end

-- ---- Count enemy deaths for backup detection ----
if radio.deathTeamId != 0 and radio.deathTeamId != me.teamId then
  mem[26] = mem[26] + 1   -- enemy deaths so far
end
Note: Radio has no effect in free-for-all (non-teams) battles or when the battle is configured with radio disabled.

scan(angle, width)

Fires a radar beam at angle with an arc of width radians.

  • Returns 0 if nothing is detected.
  • Returns a positive distance if an enemy is in the beam.
  • Returns a negative distance if a friendly is in the beam.
  • Also sets scan.dist, scan.angle, and scan.friendly.
d = scan(mem[0], 0.12)
if d > 0 then
  -- enemy at distance d, at angle mem[0]
  out.aim  = mem[0]
  out.fire = 1
end

wallDist(angle)

Returns the distance to the nearest wall in the given direction. Useful for navigation and avoiding corners.

if wallDist(me.heading) < 2.5 then
  out.moveX = 0
  out.moveZ = 0
end

User-defined functions

You can define your own functions to encapsulate reusable logic. Functions must be defined before they are called. Recursion is not allowed.

Defining a function

function name(param1, param2)
  -- body
  return value1, value2
end

The return statement can return zero, one, or multiple values separated by commas. All return statements in a function must return the same number of values. A function with no return statement (or bare return) returns no values.

Calling a function

Single return value — use in any expression:

d = distance(ex, ez)
out.speed = clamp(speed, 0.2, 1.5)

Multiple return values — use a multi-assign statement:

dx, dz = direction(ex, ez)

No return value — call as a bare statement:

update_goal(ex, ez)

Register budget

Each function's local variables (parameters + locals) occupy a fixed slice of the 60 variable registers. If all function frames combined exceed this budget, the compiler reports an error. In practice, bots with a handful of small helper functions are well within the limit.

Example — geometry helpers

-- Returns (dx, dz) unit vector from self to world point (tx, tz).
function toTarget(tx, tz)
  dx = tx - me.x
  dz = tz - me.z
  d  = sqrt(dx * dx + dz * dz)
  if d < 0.001 then
    return 0.0, 0.0
  end
  return dx / d, dz / d
end

-- Returns lead-corrected world position to aim at.
function leadShot(ex, ez, vx, vz, d)
  lead = d / 18.0
  return ex + vx * lead, ez + vz * lead
end

-- Main script
d = scan(mem[0], 0.09)
if d > 0 then
  ex = me.x + sin(mem[0]) * d
  ez = me.z + cos(mem[0]) * d
  ax, az = leadShot(ex, ez, mem[2], mem[3], d)
  out.aim  = atan2(ax - me.x, az - me.z)
  out.fire = 1
end
mem[0] = mem[0] + 0.1

Persistent memory

The persistent store has 256 float entries that survive between frames. It is split into two parts:

  • mem[0]…mem[63] — 64 individually-named slots for scalar state (radar angle, movement goal, timers, enemy data, …). Use a literal integer index.
  • Named arrays — blocks of any size declared with arr name[n], for history buffers, regression windows, and anything needing a loop index.

mem[] — scalar persistent slots

A literal index accesses persistent storage directly. A variable index (mem[i] where i is a variable) also works and accesses the same 256-entry space at runtime — useful for manual ring buffers. 

mem[0] = mem[0] + 0.08   -- radar sweep angle

-- dynamic access (ring buffer head at variable i):
i = (i + 1) % 8
mem[i] = world.time

Named arrays — arr name[n]

Declare a named array at the top level of your script. Arrays are allocated in the persistent store starting at offset 64, so they never overlap with mem[0..63]. A script may declare as many arrays as fit in the remaining 192 slots. 

arr win[30]    -- 30-entry sliding window (offsets 64..93)
arr trail[40]  -- 40-entry trail buffer   (offsets 94..133)

-- write with literal or variable index:
win[0] = world.time
i = (i + 1) % 30
win[i] = me.x

-- read:
oldest = win[head]

Literal indices are bounds-checked at compile time. Variable indices are clamped at runtime so an out-of-range access reads 0 and writes are silently dropped (no crash, no corruption).

Typical layout: mem[0..24] for scalars matching the old 25-slot ingwa layout, then arr for any history buffer.

Tutorial — building a bot step by step

Step 1: Stay alive (minimal bot)

The simplest possible bot. It doesn't move or fire — but it compiles and runs.

-- Do nothing

Step 2: Spin the radar and fire

Use mem[0] to keep track of the radar sweep angle between frames. Each frame, advance it a little and scan. 

-- Advance sweep angle
mem[0] = mem[0] + 0.10

-- Scan in that direction
d = scan(mem[0], 0.12)

-- Fire if enemy found
if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
else
  out.fire = 0
end

Step 3: Add movement

Drive toward detected enemies. Use mem[1] and mem[2] as a movement goal, updated only when you spot an enemy. 

mem[0] = mem[0] + 0.10
d = scan(mem[0], 0.12)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  -- Compute enemy world position and drive there
  mem[1] = me.x + sin(mem[0]) * d
  mem[2] = me.z + cos(mem[0]) * d
else
  out.fire = 0
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.0

Step 4: Roam when idle

If we haven't seen an enemy recently, pick a random destination so we keep moving. Use mem[3] to track the last sighting time. 

mem[0] = mem[0] + 0.10
d = scan(mem[0], 0.12)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  mem[3]   = world.time
  mem[1]   = me.x + sin(mem[0]) * d
  mem[2]   = me.z + cos(mem[0]) * d
else
  out.fire = 0

  -- Roam if goal reached or no sighting in 3 seconds
  dx    = me.x - mem[1]
  dz    = me.z - mem[2]
  near  = dx * dx + dz * dz < 2.0
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    ang    = rand() * 6.2832
    r      = world.arena * 0.6
    edge   = world.arena - 2.0
    mem[1] = min(edge, max(-edge, me.x + sin(ang) * r))
    mem[2] = min(edge, max(-edge, me.z + cos(ang) * r))
    mem[3] = world.time
  end
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.0

This is already a competitive bot. The next section shows a more advanced variant that orbits enemies.

Complete examples

Hunter — sweep, lock on, orbit while firing

A polished bot that sweeps its radar, locks onto enemies, moves into an orbit at close range while firing, and roams when nothing is visible. Uses mem[0..3]. 

-- mem[0]  radar sweep angle
-- mem[1]  movement goal x
-- mem[2]  movement goal z
-- mem[3]  world.time of last enemy sighting

mem[0] = mem[0] + 0.12
d = scan(mem[0], 0.09)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  mem[3]   = world.time

  px = me.x + sin(mem[0]) * d
  pz = me.z + cos(mem[0]) * d

  orbit  = atan2(me.x - px, me.z - pz) + 0.5
  tx     = px + sin(orbit) * 4.5
  tz     = pz + cos(orbit) * 4.5
  edge   = world.arena - 2.0
  mem[1] = min(edge, max(-edge, tx))
  mem[2] = min(edge, max(-edge, tz))
else
  out.fire = 0

  dx    = me.x - mem[1]
  dz    = me.z - mem[2]
  near  = dx * dx + dz * dz < 1.5
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    ang    = rand() * 6.2832
    r      = world.arena * 0.7
    edge   = world.arena - 2.0
    mem[1] = min(edge, max(-edge, me.x + sin(ang) * r))
    mem[2] = min(edge, max(-edge, me.z + cos(ang) * r))
    mem[3] = world.time
  end
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.1

Sniper — hang back at max radar range

-- mem[0]  radar sweep angle

-- mem[2]  patrol z

Bombardier — orbit at medium range, howitzer finishes the job

Keeps enough distance to stay in the howitzer's effective range, fires bullets when it has line-of-sight, and lobs a shell at the last known enemy position every time the howitzer reloads — even through walls. Uses mem[0..7]. 

-- mem[0]  radar sweep angle
-- mem[1]  last enemy x
-- mem[2]  last enemy z
-- mem[3]  time of last sighting
-- mem[4]  movement goal x
-- mem[5]  movement goal z
-- mem[6]  ever-seen flag (guards howitzer against firing at origin)
-- mem[7]  orbit side (+1/-1)

if mem[7] == 0 then
  mem[7] = 1
end

mem[0] = mem[0] + 0.09
d = scan(mem[0], 0.09)

if d > 0 then
  ex = me.x + sin(mem[0]) * d
  ez = me.z + cos(mem[0]) * d
  mem[1] = ex
  mem[2] = ez
  mem[3] = world.time
  mem[6] = 1

  out.aim  = mem[0]
  out.fire = 1

  -- Orbit at medium range — good for howitzer arcs
  rx   = me.x - ex
  rz   = me.z - ez
  rd   = sqrt(rx * rx + rz * rz)
  R    = max(10.0, min(22.0, rd))
  orb  = atan2(rx, rz) + mem[7] * 0.5
  edge = world.arena - 2.5
  mem[4] = min(edge, max(-edge, ex + sin(orb) * R))
  mem[5] = min(edge, max(-edge, ez + cos(orb) * R))
else
  out.fire = 0

  dx    = me.x - mem[4]
  dz    = me.z - mem[5]
  near  = dx * dx + dz * dz < 2.0
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    ang    = rand() * 6.2832
    r      = world.arena * 0.65
    edge   = world.arena - 2.5
    mem[4] = min(edge, max(-edge, me.x + sin(ang) * r))
    mem[5] = min(edge, max(-edge, me.z + cos(ang) * r))
    mem[3] = world.time
  end
end

-- Howitzer: fire at last known enemy when reloaded and in range.
-- mem[6] prevents firing at (0,0) before any sighting.
if world.howitzer.ready and mem[6] == 1 and world.time - mem[3] < 5 then
  hdx = mem[1] - me.x
  hdz = mem[2] - me.z
  hd  = sqrt(hdx * hdx + hdz * hdz)
  if hd >= 3 and hd <= world.howitzer.maxRange then
    out.howitzerX = mem[1]
    out.howitzerZ = mem[2]
  end
end

out.moveX = mem[4]
out.moveZ  = mem[5]
out.speed  = 1.1

Team Hunter — share enemy sightings via radio

Behaves like Hunter but broadcasts every enemy fix to teammates via out.radioX/out.radioZ, and uses incoming radio.tipX/radio.tipZ to steer toward enemies a teammate spotted while the radar was pointed elsewhere. In free-for-all battles the radio outputs are silently ignored. Uses mem[0..5]. 

-- mem[0]  radar sweep angle
-- mem[1]  last known enemy x (own fix or radio tip)
-- mem[2]  last known enemy z
-- mem[3]  time of last own sighting
-- mem[4]  movement goal x
-- mem[5]  movement goal z

mem[0] = mem[0] + 0.12
d = scan(mem[0], 0.09)

if d > 0 then
  ex = me.x + sin(mem[0]) * d
  ez = me.z + cos(mem[0]) * d
  mem[1] = ex
  mem[2] = ez
  mem[3] = world.time

  out.aim  = mem[0]
  out.fire = 1

  -- Share sighting with teammates
  out.radioX = ex
  out.radioZ = ez

  -- Orbit prey at close range
  orbit = atan2(me.x - ex, me.z - ez) + 0.5
  edge  = world.arena - 2.0
  mem[4] = min(edge, max(-edge, ex + sin(orbit) * 4.5))
  mem[5] = min(edge, max(-edge, ez + cos(orbit) * 4.5))
else
  out.fire = 0

  -- Update target from radio tip when our own fix is stale
  if radio.tipX != 0 and world.time - mem[3] > 1.5 then
    mem[1] = radio.tipX
    mem[2] = radio.tipZ
  end

  dx    = me.x - mem[4]
  dz    = me.z - mem[5]
  near  = dx * dx + dz * dz < 1.5
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    -- Chase last known position if still fresh, else roam
    if world.time - mem[3] < 5 then
      mem[4] = mem[1]
      mem[5] = mem[2]
    else
      ang    = rand() * 6.2832
      r      = world.arena * 0.7
      edge   = world.arena - 2.0
      mem[4] = min(edge, max(-edge, me.x + sin(ang) * r))
      mem[5] = min(edge, max(-edge, me.z + cos(ang) * r))
    end
    mem[3] = world.time
  end
end

out.moveX = mem[4]
out.moveZ  = mem[5]
out.speed  = 1.1
