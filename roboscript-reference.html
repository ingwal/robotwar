Execution model

RoboScript runs once per frame — about 60 times per second. Each frame the interpreter loads fresh sensor values, executes your code from the top, and applies any outputs you wrote before returning control to the game.

  • Regular variables are reset to 0 at the start of every frame.
  • mem[0]…mem[63] persist across frames — use them for state.
  • You have a budget of 4 000 instructions per frame. If your code takes longer, execution is cut off and the last written outputs are used.
  • All values are floating-point numbers. There are no strings, booleans, or arrays. The number 0.0 is false; anything else is true.
Tip: Think of your script like a control loop body, not a complete program. It runs repeatedly, so avoid trying to wait or loop for multiple frames — instead store state in mem[] and let the frame cycle do the looping.

Variables

Declare a variable by assigning it. All variables are floats.

speed = 1.0
angle = me.turret + 0.1
count = count + 1   -- note: count resets to 0 each frame! use mem[] for counters

Variable names are case-sensitive, start with a letter or _, and may contain letters, digits, and underscores.

Remember: plain variables reset to 0 each frame. Only mem[0]…mem[63] remember their values from one frame to the next.

Control flow

if / elseif / else / end

if hp < 20 then
  -- flee
elseif hp < 60 then
  -- be cautious
else
  -- attack
end

while / do / end

while angle < 6.28 do
  angle = angle + 0.1
  d = scan(angle, 0.1)
  if d > 0 then break end
end
Watch the budget! A tight while loop can exhaust the 4 000-instruction budget. Prefer using mem[] to continue work across frames.

loop / end — infinite loop with break

loop
  angle = angle + 0.1
  d = scan(angle, 0.12)
  if d != 0 then break end
  if angle > 6.28 then break end
end

break and continue

break exits the nearest enclosing loop. continue jumps to the top of the nearest loop.

Outputs (write to control your robot)

Outputs are applied at the end of each frame. You don't need to set all of them — unset outputs use safe defaults (stay in place, speed 1, don't fire).

NameDefaultDescription

scan(angle, width)

Fires a radar beam at angle with an arc of width radians.

  • Returns 0 if nothing is detected.
  • Returns a positive distance if an enemy is in the beam.
  • Returns a negative distance if a friendly is in the beam.
  • Also sets scan.dist, scan.angle, and scan.friendly.
d = scan(mem[0], 0.12)
if d > 0 then
  -- enemy at distance d, at angle mem[0]
  out.aim  = mem[0]
  out.fire = 1
end

wallDist(angle)

Returns the distance to the nearest wall in the given direction. Useful for navigation and avoiding corners.

if wallDist(me.heading) < 2.5 then
  out.moveX = 0
  out.moveZ = 0
end

Persistent memory — mem[0]…mem[63]

mem[0] through mem[63] survive between frames. Use them to remember: radar sweep position, movement goals, last-seen enemy data, timers, and anything else that must persist across the 60-fps execution cycle.

The index must be a literal integer — no expressions or variables as indices.

-- mem[0] = radar sweep angle (advances each frame)
mem[0] = mem[0] + 0.08

-- mem[1], mem[2] = movement target
mem[1] = 5.0
mem[2] = -3.0
out.moveX = mem[1]
out.moveZ  = mem[2]
Tip: 64 floats is enough for most bots. Suggested layout: mem[0] = radar angle, mem[1..2] = movement goal, mem[3] = last-sighting time.

Tutorial — building a bot step by step

Step 1: Stay alive (minimal bot)

The simplest possible bot. It doesn't move or fire — but it compiles and runs.

-- Do nothing

Step 2: Spin the radar and fire

Use mem[0] to keep track of the radar sweep angle between frames. Each frame, advance it a little and scan. 

-- Advance sweep angle
mem[0] = mem[0] + 0.10

-- Scan in that direction
d = scan(mem[0], 0.12)

-- Fire if enemy found
if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
else
  out.fire = 0
end

Step 3: Add movement

Drive toward detected enemies. Use mem[1] and mem[2] as a movement goal, updated only when you spot an enemy. 

mem[0] = mem[0] + 0.10
d = scan(mem[0], 0.12)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  -- Compute enemy world position and drive there
  mem[1] = me.x + sin(mem[0]) * d
  mem[2] = me.z + cos(mem[0]) * d
else
  out.fire = 0
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.0

Step 4: Roam when idle

If we haven't seen an enemy recently, pick a random destination so we keep moving. Use mem[3] to track the last sighting time. 

mem[0] = mem[0] + 0.10
d = scan(mem[0], 0.12)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  mem[3]   = world.time
  mem[1]   = me.x + sin(mem[0]) * d
  mem[2]   = me.z + cos(mem[0]) * d
else
  out.fire = 0

  -- Roam if goal reached or no sighting in 3 seconds
  dx    = me.x - mem[1]
  dz    = me.z - mem[2]
  near  = dx * dx + dz * dz < 2.0
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    ang    = rand() * 6.2832
    r      = world.arena * 0.6
    edge   = world.arena - 2.0
    mem[1] = min(edge, max(-edge, me.x + sin(ang) * r))
    mem[2] = min(edge, max(-edge, me.z + cos(ang) * r))
    mem[3] = world.time
  end
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.0

This is already a competitive bot. The next section shows a more advanced variant that orbits enemies.

Complete examples

Hunter — sweep, lock on, orbit while firing

A polished bot that sweeps its radar, locks onto enemies, moves into an orbit at close range while firing, and roams when nothing is visible. Uses mem[0..3]. 

-- mem[0]  radar sweep angle
-- mem[1]  movement goal x
-- mem[2]  movement goal z
-- mem[3]  world.time of last enemy sighting

mem[0] = mem[0] + 0.12
d = scan(mem[0], 0.09)

if d > 0 then
  out.aim  = mem[0]
  out.fire = 1
  mem[3]   = world.time

  px = me.x + sin(mem[0]) * d
  pz = me.z + cos(mem[0]) * d

  orbit  = atan2(me.x - px, me.z - pz) + 0.5
  tx     = px + sin(orbit) * 4.5
  tz     = pz + cos(orbit) * 4.5
  edge   = world.arena - 2.0
  mem[1] = min(edge, max(-edge, tx))
  mem[2] = min(edge, max(-edge, tz))
else
  out.fire = 0

  dx    = me.x - mem[1]
  dz    = me.z - mem[2]
  near  = dx * dx + dz * dz < 1.5
  stale = world.time - mem[3] > 3.0

  if near or stale or me.wallHit or me.blocked then
    ang    = rand() * 6.2832
    r      = world.arena * 0.7
    edge   = world.arena - 2.0
    mem[1] = min(edge, max(-edge, me.x + sin(ang) * r))
    mem[2] = min(edge, max(-edge, me.z + cos(ang) * r))
    mem[3] = world.time
  end
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 1.1

Coward — flee from enemies, fire backward

-- mem[0]  radar sweep angle

mem[0] = mem[0] + 0.15
d = scan(mem[0], 0.20)

if d > 0 and d < 8.0 then
  -- Enemy close: run away and shoot backward
  flee   = mem[0] + 3.1416
  out.moveX = me.x + sin(flee) * 10.0
  out.moveZ = me.z + cos(flee) * 10.0
  out.aim   = mem[0]
  out.fire  = 1
else
  -- Drift toward center
  out.moveX = 0
  out.moveZ = 0
  out.fire  = 0
end

out.speed = 1.2

Sniper — hang back at max radar range

-- mem[0]  radar sweep angle
-- mem[1]  patrol x
-- mem[2]  patrol z

mem[0] = mem[0] + 0.07
d = scan(mem[0], 0.06)

if d > 0 then
  -- Fire only when enemy is at long range
  out.aim  = mem[0]
  out.fire = d > world.radarRange * 0.5
else
  out.fire = 0
end

-- Move slowly around the edge
if me.blocked or me.wallHit then
  ang    = rand() * 6.2832
  edge   = world.arena * 0.75
  mem[1] = sin(ang) * edge
  mem[2] = cos(ang) * edge
end

out.moveX = mem[1]
out.moveZ  = mem[2]
out.speed  = 0.6
